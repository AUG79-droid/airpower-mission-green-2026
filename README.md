# Airpower Sustainability Challenge 2026

An English-language interactive decision game for learning about 2026 sustainability objectives in an Airpower Services context.

## What is included

- Six missions and twelve operational decisions.
- Immediate feedback and simulated trade-off metrics.
- Topics covering logistics, energy, packaging, REACH, SAF and project assessment.
- A claim-integrity protocol designed to prevent greenwashing.
- No externally hosted images, fonts or runtime services are required for the game.

## Important disclaimer

All operational figures and scores are illustrative training content. They do not represent Airbus performance data, environmental certification, compliance status or operational approval.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

The included GitHub Actions workflow builds and publishes the app to GitHub Pages after a push to `main`.

Expected URL:

`https://aug79-droid.github.io/airpower-mission-green-2026/`

In the repository, set **Settings → Pages → Source** to **GitHub Actions** if it is not selected automatically.

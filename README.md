# Airpower Sustainability Challenge

An English-language interactive training experience for aerospace operations, engineering, logistics, materials, energy and evidence-led sustainability decisions.

## Learning design

- **6 scenarios and 30 applied decisions** (five decisions per mission), with three alternatives and tailored feedback after each choice.
- **4 theory sections before** and **3 extended theory sections after** each mission (**42 theory sections in total**).
- Explanation of the decision criteria and, where needed, why a stronger alternative is more defensible.
- Simulated trade-off metrics across readiness, resources, compliance evidence and delivery; no certificates.
- Topics: logistics and urgent spares; energy measurement; qualified packaging and digital records; chemical substitution and REACH; SAF lifecycle accounting; evidence-based service project assessments.

## Learning path

**Study the context → evaluate 5 decisions → read the full theory review → complete the mission debrief.** The learner can reopen the theory during a mission.

## Important scope limitation

All scenarios, performance numbers, comparisons and scores are fictional instructional examples. They do not reflect Airbus operational data, authorised maintenance procedures, actual emissions savings, regulatory approvals or professional certification. Safety, traceability, airworthiness, technical configuration and applicable internal processes remain mandatory.

## Running and deployment

```bash
npm install
npm run dev
npm run build
```

The GitHub Actions workflow builds and publishes to GitHub Pages after approved changes on `main`.
